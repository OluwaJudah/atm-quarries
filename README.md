# ATM Quarries Limited — Next.js

Responsive corporate website using Next.js 15 App Router and React 19.

## Run
npm install
npm run dev

Open http://localhost:3000

## Pages
/ /about /operations /resources /sustainability /projects /contact

## Before production
- Connect the contact form to an email/CRM/API.
- Replace demo Unsplash images with licensed ATM Quarries photography.
- Add real Privacy Policy and Terms of Use.
- Confirm legal/resource wording and regulatory claims.
- Configure www.atmquarries.com and analytics.
